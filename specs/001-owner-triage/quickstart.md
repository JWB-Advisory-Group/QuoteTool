# Quickstart: Owner Action Triage

1. Run `pnpm test __tests__/dashboard-triage.test.ts`.
2. Run `pnpm lint`.
3. Run `pnpm build`.
4. Start the app with `pnpm dev`.
5. Open `http://localhost:3000/dashboard`.
6. Confirm the owner action plan appears near the top of the dashboard and shows
   the highest-priority quote first.
7. Use existing stage filters to verify the booking pipeline still works.
